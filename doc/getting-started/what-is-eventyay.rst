What is Eventyay?
=================

Eventyay is an event management platform. A single event can bring together
public event pages, registration and ticket products, orders and payments,
call-for-proposals and sessions, schedules, online-event features, badges,
and check-in.

The codebase is unified under ``app/eventyay`` and shares authentication,
permissions, services, and event data between these workflows. The feature
areas are therefore best understood as capabilities of an event, not as
separate installations.

For a code-level view of the current implementation, see the
:doc:`unified architecture </developer-guide/architecture>` page.
