Hosted platform vs self-hosted installation
============================================

The hosted Eventyay service is available at `eventyay.com
<https://eventyay.com/>`_. A self-hosted installation is operated by the
organisation running it; platform operators are responsible for deployment,
configuration, backups, monitoring, and upgrades.

Self-hosted operators should begin with the unified
:doc:`installation guide </platform-administration/installation>`.
