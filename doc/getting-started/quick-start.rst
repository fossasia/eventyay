Quick start: create and publish an event
=========================================

The shortest path for an organiser is:

#. Create an organiser account and an event.
#. Configure the event basics, languages, dates, location, currency, and
   public display settings.
#. Add the products, quotas, payment settings, and any event features you
   need.
#. Test the public event page and purchase flow.
#. Publish the event when the configuration is ready.

For the detailed, screen-by-screen event creation workflow, continue with
:doc:`/user-guide/setting-up/create-event`.
